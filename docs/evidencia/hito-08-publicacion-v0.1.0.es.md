# Evidencia de publicación — v0.1.0

[English](hito-08-publicacion-v0.1.0.md)

Fecha: 20 de septiembre de 2026.

ModelCairn v0.1.0 se publicó como **prerelease**, no como versión estable:

- [GitHub Release v0.1.0](https://github.com/sxamx/modelcairn/releases/tag/v0.1.0)
- paquetes Linux AMD64 y ARM64;
- checksums SHA-256 y SBOM SPDX;
- metadatos de tag, canal y assets verificados después de publicar;
- instalación, actualización, rollback, backup, restore y desinstalación
  comprobados previamente en Linux;
- CI protegida y QA agrupado sin hallazgos bloqueantes.

La auditoría externa recibida antes de publicar se evaluó con criterio propio.
Los problemas confirmados que afectaban el contrato de esta prerelease se
corrigieron; la deuda válida fuera de alcance quedó documentada en el
[triage público](../auditorias/2026-09-20-triage-auditoria-externa.es.md).
El informe bruto se conserva únicamente como evidencia local excluida de Git.

Con esta verificación se cerraron el Hito 8 y la Etapa G para v0.1.0.
